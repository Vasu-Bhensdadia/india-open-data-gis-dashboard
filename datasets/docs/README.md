# Dataset Documentation

This directory provides documentation artifacts for dataset sources, transformation expectations, quality checks, and lineage.

Use this space to capture:

- source dataset descriptions, license and provenance details
- transformation rules applied during GeoJSON conversion
- validation criteria and known caveats
- dataset versioning notes and supported output formats

Suggested files:

- `data-sources.md` — source dataset summaries and raw file inventories
- `processing-guide.md` — transformation and optimization expectations for processed GeoJSON
- `lineage.md` — dataset lineage and upstream/downstream dependencies
